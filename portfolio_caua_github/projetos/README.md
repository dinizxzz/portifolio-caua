# Projetos acadêmicos

Use esta pasta para organizar os projetos individuais. Para cada novo projeto, crie uma pasta com um nome simples e inclua:
- código-fonte;
- `README.md` com objetivo, tecnologias e instruções;
- imagens ou documentação, quando necessário.

Sugestão de organização:
- `html-css/`
- `python/`
- `banco-de-dados/`
- `uml-requisitos/`
