## Como executar localmente
1. Baixe ou clone este repositório.
2. Abra o arquivo `index.html` no navegador.

## Publicar com GitHub Pages
1. Crie no GitHub um repositório público chamado `portfolio-caua`.
2. Envie `index.html`, `style.css`, `README.md` e as pastas deste projeto.
3. Abra **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/ (root)` e clique em **Save**.
6. Aguarde a publicação. O endereço costuma seguir o formato `https://SEU-USUARIO.github.io/portfolio-caua/`.
