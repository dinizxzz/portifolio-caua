# Roteiro de apresentação — 5 minutos

**0:00–0:40 | Apresentação**
Olá, meu nome é Cauã Diniz Vaz de Oliveira e sou estudante de Engenharia de Software no CEUB. Este é meu portfólio acadêmico, criado para organizar meus projetos e mostrar minha evolução.

**0:40–1:30 | Organização**
O repositório possui uma página inicial, documentação e uma pasta destinada aos projetos. Cada projeto deve ter seu próprio README com objetivo, tecnologias utilizadas e instruções de execução.

**1:30–2:30 | Projetos**
Na página, apresento três áreas iniciais: desenvolvimento web, exercícios de programação e banco de dados. Conforme eu concluir atividades, vou substituir as descrições pelos projetos reais e adicionar os links dos respectivos repositórios.

**2:30–3:30 | Versionamento**
O Git permite registrar mudanças no código. A primeira versão será identificada como v1.0. Depois, novas alterações serão registradas com commits claros e versões posteriores, facilitando acompanhar a evolução do trabalho.

**3:30–4:20 | Publicação e integração**
O GitHub hospeda o código e o GitHub Pages permite publicar a página. Também vou adicionar o repositório à seção de projetos do LinkedIn para facilitar o compartilhamento profissional.

**4:20–5:00 | Encerramento**
Este portfólio será atualizado ao longo do curso com novos projetos, documentação e melhorias. O objetivo é desenvolver boas práticas e construir uma apresentação profissional da minha aprendizagem. Obrigado!
